# 🐈 Mujineko-Honkoku Tool (翻刻作業用のごくごくシンプルなツール)

ブラウザだけで動く、古文書・古典籍の「縦書き翻刻」に特化したシンプルな作業ツールです。

👉 **[いますぐツールを使う（ここをクリック！）](https://cbcb1728-na.github.io/mujicat-simplehonkoku/)**

---

 😸✌ 主な特徴
- **完全ローカル動作で安心**: 読み込んだ画像や入力したテキストは、すべてあなたのブラウザ内だけで処理されます。**外部サーバーへの送信は一切行われないため、未公開の貴重な資料でも安心してご利用いただけます。**
- **IIIF完全対応**: 国立国会図書館などのデジタルアーカイブの画像を、URLだけで直接読み込めます。ローカルの画像ファイル複数選択にも対応。
- **自由なレイアウト**: 画像とエディタの境界線をドラッグして、見やすい幅に調整可能。画像の拡大率や位置もページ移動時に維持されます。

 😸✌  基本的な使い方
1. **画像の読み込み**: 左上の「ファイル選択」または「IIIF URL」から画像を読み込みます。
2. **テキストの入力**: 画面下の横書き入力欄に文字を打ち込み、`Shift + Enter` を押すと、上の縦書きエディタに反映されます。（縦書きエディタを直接クリックして編集することも可能です）
3. **データの保存**: ツールを閉じる前に必ず「保存」ボタンを押し、`honkoku.json` ファイルをパソコンにダウンロードしてください。次回「読込」から再開できます。
